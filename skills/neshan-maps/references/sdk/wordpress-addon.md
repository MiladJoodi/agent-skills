# افزونه wordpress نشان

اطلاع

برای استفاده از کیت‌های توسعه‌ی نشان، ابتدا بایستی از طریق ثبت نام رایگان در پنل توسعه‌دهندگان نشان، اقدام به دریافت **کلید دسترسی (API Key)** برای وب‌سایت یا اپلیکیشن تحت وب خود نمایید.

- [ثبت نام و دریافت کلید دسترسی](https://platform.neshan.org/panel/signup)
- [قوانین و شرایط استفاده](https://platform.neshan.org/tos/)

اخطار

در حال حاضر افزونه وردپرس نشان منسوخ شده و نسخه جدید هنوز منتشر نشده است، تا انتشار نسخه جدید این افزونه شما می‌توانید از کیت توسعه وب بر پایه **کتابخانه جاوا اسکریپتی Mapbox** استفاده بفرمایید.

حال برای سهولت استفاده کاربران snippet code هایی برای استفاده و نمایش در وردپرس در نظر گرفته شده است. برای استفاده از این کد ها کافیست آن ها را از طریق [این لینک](https://platform.neshan.org/samples/Neshan_Maps_WordPress-CodeSnippets.zip) و یا دکمه زیر دانلود نمائید و پس از خروج از حالت فشرده و unzip کردن، به طریقی که در ویدیو توضیح داده شده است در [افزونه code snippets](https://wordpress.org/plugins/code-snippets/) آپلود نمائید و تنظیمات مربوط به نمایش نقشه را مطابق روشی که در ویدیو توضیح داده شده است در اسکریپت مربوطه انجام دهید.

[دریافت کد های نمایش نقشه نشان](https://platform.neshan.org/samples/Neshan_Maps_WordPress-CodeSnippets.zip)

### **آموزش استفاده نقشه نشان در وردپرس:**

1. افزونه code snippets را نصب نمائید. (شما می‌توانید از هر افزونه دیگری که قابلیت افزودن و اسنیپت کردن کد را داشته باشد استفاده کنید)
2. کد های اسنیپت نشان را در افزونه آپلود کنید.
3. به اسکریپت نمایش نقشه رفته و کلید دسترسی خود را در قسمت API\_KEY قرار دهید.
4. مختصات مرکز نمایش نقشه را مشخص نمائید. ( سایر تنظیمات را نیز می‌توانید در همین بخش انجام دهید)
5. با مراجعه به تکه کد Neshan Map Container، کد کوتاه (Short Code) نمایش را کپی کنید و در هر کجای وردپرس که می‌خواهید نقشه را نمایش دهید.

در ویدیوی آموزشی فوق تنها امکانات پایه به نقشه افزوده شده است، شما می‌توانید با استفاده از جاوا اسکریپت و **کتابخانه mapbox-gl** امکانات بیشتری را به نقشه خود اضافه نمائید.
