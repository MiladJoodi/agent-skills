## اپلیکیشن‌های نمونه نقشه نشان

در اپلیکیشن‌های نمونه‌ای که با Neshan Android SDK پیاده‌سازی شده‌اند می‌توانید قابلیت‌های مختلف نقشه‌ی نشان را تست و بررسی نمایید. قابلیت‌هایی مانند رسم خط، چند ضلعی، نمایش موقعیت بر روی نقشه، تغییر شیب و جهت نقشه و همچنین تغییر استایل نقشه‌ی زیردست.

## اپلیکیشن Starter

اپلیکیشن استارتر نقشه نشان در واقع یک پروژه آموزشی جهت آشنایی توسعه‌دهندگان با قابلیت‌های مختلف SDK نقشه نشان است. در این پروژه نحوه استفاده از کلاس‌های مختلف موجود در پلتفرم نقشه نشان آموزش داده شده‌است. با استفاده از ویکی کامل و به‌روز و توضیحات موجود در source code پروژه به راحتی می‌توانید از قابلیت‌های مختلف این پلتفرم در اپلیکیشن خود استفاده کنید.
